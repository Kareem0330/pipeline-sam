# Chaîne de devis Sam'Déménage

Dépôt privé : tout ce qu'il faut pour produire les devis de Sam'Déménage avec Claude Code, sur un PC Windows.

Commence par **[LISEZ-MOI.md](LISEZ-MOI.md)**, puis le [guide d'installation](guides/01-installer-le-dossier.md).

Les clés vont dans un fichier `.env` local, jamais dans ce dépôt. Les devis des clients restent sur le PC, dans `donnees/`, et ne sont pas envoyés ici.
